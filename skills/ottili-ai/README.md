# Ottili AI Skills

Skills in this package target the Ottili AI runtime, Ottili Velo, and Ottili ONE platform integrations.

## Planned skills

Examples that belong here (not yet published):

- `ottili-module-tools` – Unified API module operations
- `ottili-approval-workflow` – Human-in-the-loop approvals
- `ottili-company-context` – Tenant and company context loading
- `ottili-browser-research` – Browser-based research flows

These skills are bundled with Ottili ONE deployments. They will be published here as they are generalized for public use.

## Add a skill

Follow the same process as community skills, but place files under `skills/ottili-ai/<skill-name>/` and set `"package": "ottili-ai"` in `catalog.json`.
