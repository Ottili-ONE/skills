# business-de — German Business & Integration Skills

Ten researched Agent Skills for coding and operations agents working on the Ottili
platform. Each skill follows the open Agent Skills standard (agentsskills.io):
a folder with `SKILL.md` (YAML front matter), optional `scripts/`, `references/`
(`DESIGN.md`, `EVALS.md`, `SOURCES.md`, `*-procedure.md`) and `assets/`.

> Install hint: `bash ../scripts/install.sh business-de/<skill>` (see
> `../scripts/install.sh` for the one-liner). The catalog entry is regenerated by
> `../scripts/build-index.py`.

## Skills

- **bank-reconciliation-camt** — Parse CAMT.053/MT940 statements, match postings to
  open items with multi-key heuristics, detect duplicates and unallocated
  differences, produce a reconciled Kontoauszug.
- **carrier-apis-de** — Ship parcels with German carriers (DHL, DPD, GLS, Hermes,
  UPS) via official REST/SOAP APIs only; labels, tracking, returns, charge
  reconciliation.
- **datev-extf** — Produce and validate DATEV EXTF (Exportdateiformat) booking
  stacks, Datenservices exports and test fixtures for German accounting
  integrations.
- **dsgvo-ai-act-labeling** — Classify AI content under GDPR (register entry,
  DPIA) and the EU AI Act Art. 50 labelling, and produce the human-review
  evidence that exempts it.
- **gobd-archive** — GoBD-compliant retention, immutability,
  Verfahrensdokumentation and audit-ready export for German accounting data.
- **publish-reconcile-wp-meta** — Publish idempotently to WordPress and Meta
  (Facebook/Instagram) and reconcile until the publish is observable.
- **skr-journal-mapping** — Map SKR03/SKR04 ledger accounts to journal entries,
  tax keys (19/7, 16/1, 06/0, 09/0, 13/0) and automatic Buchungszeilen; enforce
  period locks before the fiscal close.
- **webhooks-safe** — Receive, verify (HMAC/OAuth2), deduplicate and safely
  forward inbound webhooks without enabling SSRF.
- **xrechnung-zugferd** — Generate, validate and archive German e-invoices
  (XRechnung / ZUGFeRD / Factur-X) per EN 16931 and the §14 UStG e-invoicing
  obligation.
- **ust-edge-cases** — German VAT edge cases: reverse charge §3g, Kleinunternehmer
  §19, intra-EU B2B 06/0, OSS/IOSS, cent rounding and e-invoice interplay.

## Quality bar

Every skill ships `references/EVALS.md` (≥5 realistic prompts + 3 near-miss
prompts with expected behaviour and failure signs) and `references/SOURCES.md`
(≥6 primary sources with URL + retrieval date). Validate with:

```bash
python3 ../scripts/validate_skill.py business-de/<skill>
python3 ../scripts/validate_skills.py business-de/<skill>   # standard + EVALS/SOURCES
```

All ten skills pass `validate_skill.py --all` (see `HANDOFF.md` for the current
state and what to re-verify).
