# Contributions

Dieses Repo ist ein einfacher Skill-Host für Ottili-ONE (Claude Code, Codex, OpenClaw, Ottili Velo).

## Skill hochladen

1. Erstelle einen Ordner: `skills/<skill-slug>/`
2. Lege deine Skill-Datei dort ab: `SKILL.md`
3. Achte darauf, dass dein YAML-Frontmatter am Anfang der Datei steht und mindestens diese Felder enthält:
   - `name`
   - `description`

## Konventionen

- Verwende im Pfad den gleichen Slug wie im `name:`-Feld im Frontmatter.
- Halte die Datei `SKILL.md` als vollständige, ausführbare Skill-Definition.
