# skills

Claude Code, Codex, OpenClaw and Ottili AI Skills - powered by Ottili ONE (https://ottili.one)

## Struktur

- Eigene Skills liegen unter `skills/<skill-slug>/SKILL.md`
- `<skill-slug>` entspricht dem `name:`-Feld im YAML-Frontmatter der `SKILL.md`

## Eigene Skills hochladen

1. Lege einen Ordner an: `skills/<skill-slug>/`
2. Kopiere deine Skill-Beschreibung als `SKILL.md` in diesen Ordner
3. Stelle sicher, dass das YAML-Frontmatter am Dateianfang beginnt (erste nicht-leere Zeile)

Wenn du willst, kann ich als nächsten Schritt auch ein kleines `manifest.json` für Menschen ergänzen. Aktuell ist die Struktur so minimal gehalten, wie das Repo es im Kern ist: Skills sind schlicht Dateien im richtigen Pfad.
